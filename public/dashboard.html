    Connect your website

    Send requests to SaveHatke AI with your API key.

    curl https://api.savehatke.ai/v1/chat \
  -H "Authorization: Bearer $SAVEHATKE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "savehatke-1",
    "messages": [
      { "role": "user", "content": "How can you help me?" }
    ]
  }'
    Replace the endpoint with your deployed SaveHatke AI API base URL when it is live.
